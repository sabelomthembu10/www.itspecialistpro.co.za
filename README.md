# IT Specialist Pro Online Store

This is a responsive front-end store based on the supplied IT Specialist Pro artwork.

## Features
- Responsive service catalogue
- Add to cart / remove / quantity controls
- Cart persists in browser localStorage
- Checkout form
- EFT/bank-payment instructions
- WhatsApp order generation
- Mobile-friendly design

## Important
The checkout is functional for collecting order details and preparing a WhatsApp order. It does not itself process card payments or automatically verify EFT payments.

For real online card/instant payments, connect a South African payment gateway through a secure backend (for example PayFast, Yoco, Peach Payments, Ozow, or another gateway). Do not put secret API keys in browser JavaScript.

For a production system with real payments, an admin dashboard, order database, automatic payment verification and WhatsApp notifications, add a backend/database and gateway webhooks.
